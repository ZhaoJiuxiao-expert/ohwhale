# 哦鲸鲸 · OhWhale

哦鲸鲸 1.7.0 是一款 Windows 和 Android 聊天软件。打开即回到蓝白色聊天列表；宿舍、旅行、小游戏统一放在「群聊」里。打开会话后可以专注聊天，3D 布置按需打开，关闭后回到原来的草稿。DeepSeek、千问、Kimi、豆包四位国内预设伙伴提供连接建议，确认发送范围后可一起连接；已有 API 和角色设置会保留。用户仍可收发文字、图片和语音，通过鲸鲸号或二维码添加好友，并编辑和分享角色卡。

1.7 操作与验收范围见 [聊天布局更新](docs/chat-layout-1.7.md)，场景说明见 [小屋 1.6](docs/house-1.6.md)，协议入口为 [帮助与约定](https://47.86.23.218/terms)。2026-11-09 19:08（北京时间）曾通过 1.6 真实托管短消息验收：DeepSeek、千问、Kimi 在零好友的小屋依次回复，豆包另行回复成功。这是历史连通证据；1.7 的本地界面验收不代表重新完成公网、真机或真实模型验收，实际可用性仍受网络、额度和服务状态影响。

## 先和伙伴住进小屋

点击主导航「群聊」，可进入宿舍、旅行和游戏房间。每间房有你和三位 AI；发消息前选择伙伴，点击发送才会请求回复。不需要先开通好友身份或邀请真人。首次连接可在引导页查看实际模型与发送范围，确认后使用免填密钥的托管入口；服务不可用时会提示，保留已有连接，也可从更多设置使用自己的 API。四位预设角色不保证对应四家厂商一直在线；实际使用模型以确认页为准。

场景中可旋转、缩放、点击物件，也可导入自己的 GLB 或全部资源内嵌的 glTF 2.0。每件物品的「能一起玩」和「让伙伴知道」由你分别决定，默认不向伙伴公开；具体格式限制、发送文字预览和保存方式见 [模型导入与分享范围](docs/house-1.6.md#把自己的小屋带进来)。

## 运行桌面端

开发环境使用 Node.js 24 和 pnpm，Android 构建另外需要 Windows、Python 3 和带有 javac 的 JDK。先在仓库根目录运行：

```sh
pnpm install --frozen-lockfile
pnpm run build
pnpm start
```

原有美术资源的来源和授权范围见 [第三方说明](THIRD_PARTY_NOTICES.md)。源码中保留图片引用、角色设定和表情素材索引。要还原发行版的头像、立绘和表情，请从有权使用的本地工程复制以下路径，保留文件名及相对路径：

- `src/ui/assets/`，包括角色图片和 `stickers/` 子目录
- `src/ui/app.ico`，Windows 图标
- `android/res/drawable/app_icon.png`，Android 图标，构建时会从 `src/ui/assets/deepseek-avatar.png` 重新生成

恢复这些资源后再打包或运行需要验证内置图片的测试。基本使用步骤见 [使用指南](docs/使用指南-1.3.1.md)；新增头像与表情收藏操作及验证范围见 [Android 1.3.2 更新说明](docs/Android-1.3.2.md)。网络服务地址位于 `src/data/network-defaults.json`。

## 换头像与收藏表情

在聊天中打开「角色资料」→「编辑角色与模型」，点击「换个头像」。选择图片后可以预览，点击「保存角色」才会生效；取消编辑会保留原头像。支持 PNG、JPEG、WebP 和 GIF 输入，单张最大 10 MB，头像按静态图片显示。自定义头像会保存在当前设备，导出角色卡时也会随卡携带。

手机长按聊天图片，或电脑右键点击图片，再点「收藏为表情」。普通点击也可打开大图并收藏。点输入框旁的笑脸进入「角色表情库」→「我的表情」，选中图片后点「插入消息」，确认后发送。收藏会在重启后保留，同一张图片重复收藏只保留一份。滑动浏览时不会触发长按收藏。

收藏的图片再次发送时会作为图片附件传递，朋友无需预先安装你的表情库。发送给 AI 时需要所选模型支持图片理解。收藏只保存在当前设备，不会自动上传到公共图库。

## 伙伴主动问候

在「角色资料 → 编辑角色与模型」开启问候，可选固定时间或自然节奏。到时使用已授权的模型，结合人设、明确保存的记忆和近期文字对话生成消息。Android 可在「设置 → 通用偏好」单独同意后台问候并允许系统通知；电脑需保持程序运行。每天限次、失败退避、免打扰、近期聊天冷却和重复消息抑制会共同生效，设置页可以查看送达状态。

具体操作、费用与安卓系统限制见 [主动问候 1.4.0](docs/主动问候-1.4.0.md)。后台不是准点闹钟，强制停止应用后需重新打开。

## 多人和 AI 群聊

打开「群聊 → 打开真人群聊」，可创建群组，通过好友邀请、邀请码或二维码图片加入；群内顶端有「邀请真人」。支持群主与细分管理员权限、入群审核、禁言、移除与封禁、慢速模式、置顶、历史可见范围和群主转让。群中可以添加多个 AI 角色；点选 @ 角色后才会触发回复，每条消息最多点名 1–3 位。「请谁来回复？」可以多选后点「选好了」，也可以点关闭、点面板外侧或按 Esc 收起。

群聊是服务端同步的云端群，不是端到端加密 P2P 群。加入前会说明数据去向。角色只共享公开人设，不携带私聊、私人记忆和密钥；AI 主人需保持电脑应用运行，Android 需保持前台。操作和限制见 [群聊 1.5.0](docs/群聊-1.5.0.md)。

## 好友与公开动态

「动态」新增「好友」「公开」「我的发布」，原有「本机」内容保留且不会自动上传。发布时由你选择好友可见或所有注册鲸友可见并确认；支持点赞、取消点赞、评论、移除评论、隐藏动态和调整可见范围。服务器每次读取重新核验权限，展开评论也会定时刷新。完整操作与数据边界见 [群聊与公开动态 1.5.0](docs/群聊-1.5.0.md)，本次验证范围见 [1.5.0 交付验收](docs/验证-1.5.0.md)。

## 测试和构建

`pnpm test` 运行 Node 测试。WebRTC 测试使用 Playwright 和已安装的 Microsoft Edge。可通过 `P2P_BROWSER` 指定 Chromium 可执行文件。APK 归档测试需要 Python 3。

在 Windows 上，运行 `pnpm run build` 和 `pnpm run package` 生成桌面应用目录；如已有 Electron 离线压缩包缓存，可通过 `ELECTRON_ZIP_DIR` 指定目录。

运行 `python scripts/android-setup.py` 可安装 Android SDK 35。安装时由构建者审阅 SDK 许可。准备好图片后，设置 `OHWHALE_ANDROID_SIGNING_DIR` 指向本地签名目录，并在环境中设置 `OHWHALE_SIGNING_PASSWORD`。已有签名使用文件名 `ohwhale-local.jks` 和别名 `ohwhale-development`。首次构建独立测试版本时可显式执行 `node scripts/android-build.cjs --initialize-signing`，后续运行 `node scripts/android-build.cjs`。复用原版安装身份需要原签名密钥，独立生成的密钥适用于自己的安装身份。APK 输出到 `android/output/`。

## 代码目录

| 路径 | 内容 |
| --- | --- |
| `src/ui/` | React 聊天、好友面板、角色工坊和样式 |
| `src/core/` | 消息、角色、语音、模型访问和本地存储 |
| `src/p2p/` | WebRTC 连接及传输 |
| `src/mobile/`、`android/` | 移动端适配和原生接口 |
| `server/` | 信令、好友服务、模型代理及部署模板 |
| `scripts/`、`tests/` | 构建工具和自动化测试 |
| `src/data/`、`docs/`、`licenses/` | 默认配置、素材索引、协议和许可证 |

部署前请阅读 [好友服务协议](docs/friends-v1-contract.md)、[模型代理协议](docs/managed-ai-v1-contract.md) 和 [公网部署说明](docs/公网P2P部署与验收.md)。密钥、签名文件、用户数据与实例运行配置由各部署环境单独管理。
