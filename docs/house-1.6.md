# 哦鲸鲸小屋 1.6

说明日期：2026-11-09。本文说明 1.6 的操作、数据范围和已做的检查，不代表所有线上模型、设备或安装包均已验收。协议入口：[小屋帮助与约定](https://47.86.23.218/terms)。

## 不添加好友，也能一起聊

从首页进入宿舍、旅行或游戏房间，即可建立你和三位 AI 伙伴的房间。不需要先添加真人好友、创建云端群或完成鲸鲸号注册。这里的本机房间与「群聊」中的服务器同步群组是两套独立功能。

首次进入时，可查看 DeepSeek、千问、Kimi、豆包四位国内预设伙伴的连接建议。引导会列出实际模型及内容发送范围；确认后可一起连接，不要求每位伙伴都手填密钥。已准备好的连接会保留，包括自定义服务与密钥。托管菜单暂不可用时会提示，也可以在更多设置中选择自己的 API 或已有连接。

角色名字与实际承接请求的模型分别显示。若对应模型暂不在菜单中，确认页可能显示由其他可用模型演绎；请按确认页判断实际服务，不把角色形象当作模型厂商的连接证明。自行导入的其他角色仍可能需要选择连接。

2026-11-09 19:08（北京时间），通过现有公网托管服务完成四款真实模型的短问候验收：DeepSeek、千问、Kimi 在同一零好友房间依次回复，豆包另行回复成功。用的是独立测试身份与人工编写的验收消息，没有使用用户私聊。详见 [本次验收](release-1.6-verification.md)。

## 宿舍、旅行与今晚的一局

| 入口 | 可以做什么 | 什么时候会请求模型 |
| --- | --- | --- |
| 宿舍 | 三位伙伴同房聊天，布置小屋，介绍你选择的小物件 | 选择一至三位伙伴并发送消息时 |
| 旅行 | 沿预设地点和小目标继续一段想象旅程 | 发送聊天、请伙伴回应时；切换地点本身不请求模型 |
| 游戏 | 石头剪刀布、猜数字；结果和进度可保留 | 游戏规则与对手策略在本机运行；另发消息请伙伴点评才请求模型 |

旅行地点和事件属于故事内容，不是实际出行、预订、实时导览或现实陪同。小游戏对手的出招与判断由本机程序产生，不冒充模型思考。开场文字有独立的预置来源，失败或未连接时不会补上一段假模型回复。

一轮选定多位伙伴时，回复按顺序执行。可以停止；失败后由你手动重试，已经成功的发言不会被再次请求。离开前台、重启和取消都会中断待完成请求，不会在重开后偷偷续跑。恢复房间会保留聊天、场景和游戏记录，但恢复记录不会自动发消息。

## 把自己的小屋带进来

默认小屋由程序生成木桌、床、门、台灯、书架等几何体，不下载房屋图片、模型或贴图。可以拖动旋转、滚轮或双指缩放，并用「重置视角」重新看全小屋。点击画面中的物件，或直接从清单中选择，都能编辑介绍。

「导入自己的3D模型」接受以下文件：

| 项目 | 当前范围 |
| --- | --- |
| 格式 | glTF 2.0 的 `.glb`，或所有缓冲区与图片都内嵌的 `.gltf` |
| 大小 | 单文件不超过 16 MiB |
| 网络与路径 | 不接受外部 URL、本机路径、单独的 `.bin` 或外置贴图；加载器另外阻止外部请求 |
| 压缩与扩展 | 暂不支持 Draco、KTX、扩展或脚本；请导出标准、非压缩、非稀疏模型 |
| 几何预算 | 最多 512 个节点、128 个网格、256 个几何片段；顶点总量最多 30 万、三角形最多 20 万，共享网格实例也计算在内 |
| 贴图 | PNG/JPEG，最多 16 张；单边不超过 4096，总像素最多 1600 万 |
| 可编辑介绍 | 最多标注 24 个部件；部件名称 80 字符、介绍 600 字符，全部名称和介绍合计不超过 6000 字符 |

文件在界面和本机存储入口分别校验。校验不通过会显示原因并保留原场景；显示失败时仍可通过物件清单编辑与操作。部分符合格式的文件也可能因为设备图形能力、材质或导出方式无法正常显示，建议先用简单模型试导入，再逐步增加细节。

模型保存在本机独立目录，按内容摘要标识；部件使用稳定的节点标识。模型不保存在浏览器 localStorage，也不作为附件自动发给模型服务。桌面端使用本机加密能力，Android 使用应用的加密文件存储；请保管好设备与备份。导入和切换模型后不会沿用旧模型的可见权限。

## 伙伴能知道什么

选择物件后，可填写名称和介绍，分别勾选「能一起玩」与「让伙伴知道」。新导入部件和默认小屋的 AI 可见权限均为关闭；没有勾选的介绍只留在本机，不进入场景发送摘要。修改后点击「保存小屋设置」才生效，背景刷新不会覆盖尚未保存的输入。

两项都勾选后，可以查看或使用物件，例如坐下休息、开关灯。这些动作写入场景记录，用作之后的聊天情节；不会让任意导入网格自动具备物理、骨骼动画、门铰链或真实灯光开关。点击互动本身不请求模型，接着由你在聊天中选择伙伴并明确发送。

展开「伙伴能知道什么」可查看实际场景摘要原文，包括当前地点、目标、进度、已允许公开的物件和仍符合权限的近期动作。取消某物件的公开权限后，它的介绍和相关动作会从后续摘要移除。已发送给服务、或已经出现在历史消息中的文字不会因此被远程撤回。

伙伴当前读取你授权的文字与动作，不会自动视觉理解整座3D小屋。模型回复还会使用该房间的必要聊天上下文与所选角色的公开人设；不会把私人插件记忆、其他私聊或模型文件拼入本机房间请求。场景介绍和其他角色发言按参考资料处理，不作为系统指令。

## 保存、费用与协议

本机存档不等于离线生成。请求真实模型时，选定的房间文字和允许公开的介绍会经过你确认的服务端或自定义接口；费用、频率和预算限制仍按连接服务执行。没有因为小屋新增功能而放宽托管预算保护。保存场景、查看帮助、推进地点和执行本机游戏规则不调用付费模型。

「小屋帮助与约定」打开 [协议页面](https://47.86.23.218/terms)，失败会显示提示。协议说明不会代替每次必要的分享选择；小屋内的可见开关与实际发送预览仍保留。原有用户图片、角色参考图与表情的权利范围见 [第三方说明](../THIRD_PARTY_NOTICES.md)，导入模型也请使用自己有权使用的素材。
