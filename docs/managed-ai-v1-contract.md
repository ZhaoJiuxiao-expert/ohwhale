# Managed domestic AI v1

User 2026-11-05 explicitly requests server-held API credentials, easy default DeepSeek conversation, common domestic models through same endpoint, foreign models remain BYOK, with security and per-person maximum request frequency. This is a product service, not external model delegation for development. No secret in app/installers/docs/logs.

## Server

New `server/managed-ai.cjs`, initialized only when API key + private writable usage directory configured. Fixed upstream `https://api.atlascloud.ai/v1/chat/completions`, allowlisted domestic model IDs from server-owned JSON catalog; no request base URL, Authorization override, tools, function calling or arbitrary model. Foreign models rejected, not just hidden in UI. Default catalog entry alias `deepseek`, others catalog provided separately by root. Constructor fetch/clock injectable for local fixture only. Public routes under existing HTTPS origin:

- GET `/v1/managed/models`: `{enabled,models:[{id,name,vision}],limits:{perMinute:6,perDay:60,concurrent:1,globalPerDay:600,maxOutputTokens:4096},privacy:{processor:'AtlasCloud',region:'Hong Kong server; upstream processing location not verified'}}`. model id = actual upstream id; catalog includes label/vision boolean. False enabled if no key, no phantom readiness. Public metadata contains no credentials.
- GET `/v1/managed/usage`: bearer device token authenticated via FriendsStore; return `{day,requestsUsed,requestsRemaining,perMinute,perDay,concurrent}`. UTC day explicitly labeled client side.
- POST `/v1/managed/chat/completions`: same device auth; body `{model,messages,stream:false|max_tokens...}` accept only model/messages/stream/max_tokens, server caps and builds fresh payload. Return standard non-stream Chat Completions `{choices:[{index:0,message:{role:'assistant',content},finish_reason:'stop'}],usage?}`. Ignore caller stream preference, response JSON compatible Harness. Mask upstream errors; 429 `{error:{code:'USER_RATE_LIMIT'|'USER_DAILY_LIMIT'|'GLOBAL_DAILY_LIMIT'|'CONCURRENT_LIMIT',message:...},retryAfterSeconds?}` with header.

Limits: per identity 6/min, 60/UTC day, 1 concurrent; per IP 12/min and 180/day; global 600/day and 4 concurrent. Global reserved budget 2,000,000 token-equivalent units/day, per identity120,000/day; reservation uses conservative UTF8 text byte count + 4096 output + image upper-bound. Text max48k UTF8 total, at most25 messages, bounded data-image types/no remote image URLs; vision limited catalog supports. Request body image-inclusive max8MB and2images aggregate4MB decoded. If costly conservatism rejects long context surface actionable length error. Persist quota reservation before upstream call, include failures/cancel; no retry; 75s timeout/disconnect cancellation, bound reply bytes; strict allowed roles/content/finish reasons, reject empty/length/tools/invalid responses, ensure no raw key echo returns. Usage log stores time, hashed identity/ip, model, counters/outcome only; no prompts, image, reply, raw key. Quotas survive restart; corruption/disk-full fails closed; preserve logs, bounded disk. Do not add broad CORS or expose server key.

## Client

`ManagedClient` or FriendsClient internal authorized helper; only dedicated APIs reach renderer: `managedCatalog()`, `managedUsage()`, `managedConnect({agentId,model,consent:true})`. On connect, explain messages/images + relevant confirmed memory sent to this server and AtlasCloud upstream. If no device identity, register via existing friendsEnable with nickname supplied by local settings or `一位鲸友`, explicitly noted under consent. Fixed origin. Bind a reserved managed provider to selected role; provider `managed:true`, no `apiKey` at all, `hasKey:false`. Do not forge hasKey or put device credential in ChatStore provider. Regular saveProvider cannot change managed endpoint or inject provider.managed. Existing user BYOK entries preserved and freely usable for foreign models.

Harness constructor accepts `managedRequest` callback; managed provider selection skips BYOK key requirement but requires explicit consent and callback. Request goes through dedicated client server request using encrypted device credential in privileged context, returns `{text,usage,finish:'stop'}`; no hidden external retry. Windows net.fetch; Android dedicated managed native route uses endpoint-bound friend identity purpose, separate from model HTTP and existing friends requests. ChatStore managed schema validated on load and public view explicitly marks managed; stable safe reserved id, catalog validated server model requested. UI checks `provider.managed || provider.hasKey` for ready.

UI ConnectionGuide default simple domestic tab: defaultDeepSeek, choose other domestic models, one clear consent and start button; alternate BYOK tab for own/foreign API; model names/limits actual catalog. Do not imply domestic provider means mainland data residency. Failure/no quota keeps draft. Existing persona pipeline, memory boundaries, role share explicit quota authorization remain.

Tests: real mock upstream only unless root explicitly tests live.
