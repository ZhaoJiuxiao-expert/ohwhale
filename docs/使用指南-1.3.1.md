# 哦鲸鲸 1.3.1 简易指南

## 开始使用

Windows：解压整个 Windows 压缩包，打开其中 OhWhale-win32-x64 文件夹，双击 OhWhale.exe。请保留文件夹内的配套文件。

安卓：在手机上打开 APK 安装；如系统要求，请按手机提示允许本次安装。实际兼容性仍需在目标设备上验证。

## 与角色聊天

新建聊天并选择角色。选择“直接聊 · 国产模型”，默认可选择 DeepSeek；阅读数据发送说明、勾选同意后连接，无需自行填写 API 密钥。聊天文字、图片和相关已确认记忆会经哦鲸鲸服务器发给 AtlasCloud 和所选模型；上游具体处理地点尚未核实。

托管服务限制为每个设备身份每分钟最多 6 次、每天最多 60 次、同时 1 个请求。每日额度按 UTC 零点重置，即北京时间早上 8 点。服务总额度、网络状况或繁忙情况也会影响可用性。设置中的托管模型页面可以查看剩余次数。

想使用自己的国内或海外模型，可选择“自己的 API”，填写服务地址、模型名称和自己的 API Key，阅读并同意后连接。该服务产生的费用和服务条款由你与相应服务商约定。

## 添加好友

在聊天页选择添加好友，按提示设置昵称、确认同意并领取鲸鲸号。可以让朋友扫描你的二维码，或者输入朋友的鲸鲸号发送申请；对方同意后成为好友。聊天连接仍需对方接听。二维码解析后请先核对，再发送申请。

鲸鲸号对应设备身份，不是实名认证。请妥善保管设备和应用数据；不要把二维码当成设备凭据或账号恢复方式。双方在线、网络与服务可用是建立连接的必要条件，跨网络连接情况以实际测试为准。

## 当前服务状态

云端托管服务已完成一次真实 DeepSeek 请求验证；这不代表所有模型和使用场景均已验证。好友功能已使用同一台电脑上的两个隔离客户端，通过公网服务完成实际接听、双向消息、断线重连和重启后数据保留验证；本次没有检查实际连接线路，因此不能证明使用了中继，也不能证明跨 NAT 或安卓设备上的连接表现。安卓目标设备的安装与使用情况仍需另行验证。若托管服务暂不可用，可以使用自己的 API。
