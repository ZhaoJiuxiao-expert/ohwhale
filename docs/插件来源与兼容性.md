## 推荐组合与边界

本应用优先保持现有模块化主进程：`Persona → Memory → Session/Harness → Provider → Channel`，外围挂 `Scheduler`、`Diary`、`Sticker` 和 `Speech`。这是一套适配本应用的独立实现方案，不声明使用了 DSH 或 AstrBot 的完整运行时。

先完成用户可编辑的人设、明确的模型绑定、用户审核的记忆、默认关闭的主动问候、可追溯的本地日记与手动贴纸。人格和记忆可以在本地生效，但生成聊天、日记或问候仍要用户配置可用的模型服务；提示词不能替代真实模型接通。

DeepSeek 负责聊天生成应遵循其[官方 Chat Completions 接口](https://api-docs.deepseek.com/api/create-chat-completion/)。ASR/TTS 是独立的语音服务边界；若采用百炼，按其[语音识别文档](https://help.aliyun.com/zh/model-studio/asr-model/)和[语音合成文档](https://help.aliyun.cn/zh/model-studio/non-realtime-tts-user-guide)另外配置服务、模型与凭据，不能直接把聊天模型 ID 当语音模型 ID。

本次没有评估六个仓库所有历史版本、全部安全性或所有第三方素材的授权。上述“适合原生实现”仍是方案，不构成已经上线或真实模型效果验证；应由集成后的功能与测试结果逐项更新实际状态。
