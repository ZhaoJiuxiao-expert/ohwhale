# 1.7 聊天布局与验收边界

日期：2026-11-10。源码基于 1.6，目标平台 Windows x64、Android（版本号 10700）。

## 实际修正

默认开屏从小屋改为聊天列表；主导航使用聊天、群聊、动态、我四个入口。群聊大厅集中放置真人群入口和宿舍、旅行、小游戏。桌面与手机选中会话后收起外围栏，通过返回按钮回到列表或大厅。配色统一为蓝白。

云群选人面板支持多选、选好了、X、Esc、外点与触发按钮切换；外点输入框不会抢回焦点，输入法组字时的 Esc 不触发关闭。切群或隐藏页面时收起面板。

3D 布置采用独立模态面板，避免在桌面挤窄聊天、在手机隐藏原对话。当前房间内关闭再打开保留未保存标注和聊天草稿；离开房间前仍需保存场景编辑。加载中的 3D 入口禁用，避免空房间打开。重复从大厅进入相同宿舍会重新选中已有房间。

## 本机验收

- 基础 Node 测试：309 项通过；版本统一检查已更新至 1.7.0 / 10700 并通过。
- 实际 Electron 界面与真实本机 IPC：至少 136 项通过，覆盖 360、390、1280 宽度、真人身份注册及群加入（本机模拟服务）、AI 房间、私聊、选人关闭、草稿、场景编辑以及发向本机模拟模型的消息。无页面脚本错误。
- 房间组件：54 项通过；3D 场景专项：11 项通过，含导入、点击、权限预览与移动尺寸。
- 安装包另做版本、签名、内容一致性检查与独立资料目录启动测试；具体文件哈希及最终结果放在随下载提供的验收 JSON 中。

本轮未以实体小米设备安装、跨公网真人群聊或新的托管模型实聊作为验收。上述本机模拟结果不可替代这些验证。服务器协议和收费接口权限未因本次界面调整扩大。

## 代码分析与辅助审阅

通过 GitHub 获取 [codegraph-setup](https://github.com/nuoyanruoshui/CodeGraph-Skill)，核对其使用的 [CodeGraph](https://github.com/colbymchenry/codegraph) 1.6.2 后，在独立源码镜像进行试用。关闭遥测、自动更新和文件监视，没有更改主仓库 Git 钩子、MCP 权限或用户配置。

镜像仅含公开程序代码，排除聊天、密钥、角色数据及媒体资源。一次完成的索引包含 61 个 JS/JSX 文件、1,127 个节点和 4,537 条边；查询找到 App 到 GroupHub、GroupWorkspace、RoomWorkspace 的 JSX 调用。静态源码核对确认大厅、真人群与 AI 房间的入口、返回和专注状态属性对应一致。索引是当时源码快照，JSX 边带启发式标记；未纳入测试文件，因此“未找到测试”不能解释为项目没有测试。运行时验收仍是界面结论的依据。

按用户指定，通过现有网关调用了一次 Opus 5.5 辅助分析面板关闭和焦点行为。返回的示例代码不完整，未直接执行或复制；仅参考其中经本地验证的输入法、焦点恢复和页面切换建议。最终代码由本地整合并用上述测试验证。
