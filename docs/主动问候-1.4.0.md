# 哦鲸鲸 1.4.0 · 伙伴主动问候

这一版补齐“调度触发 → 带上人设和记忆调用模型 → 写入聊天 → 通知”的流程。问候需要角色已连接且已授权的模型。没有接好模型时不会用预置句子冒充模型回复。

## 怎么打开

1. 打开聊天，进入「角色资料 → 编辑角色与模型」，开启「让她主动来问候」。
2. 选择「每天的小约定」或「自然地想起你」，设置每天从几点开始。
3. Android 如需离开应用后收到问候，到「设置 → 通用偏好 → 让伙伴偶尔来找你」，阅读并勾选同意后，点「允许后台小问候」，允许系统通知。不开后台也可以在应用前台收到问候。
4. 同一处可查看各角色今天的送达、尝试与等待状态，或暂停后台问候。关闭角色的问候开关或主动问候插件也会停止相应计划。

## 节奏和记忆

- 固定时间模式在约定时间之后检查；自然模式在该时间附近增加每天变化的 0–60 分钟间隔，尽量接续真实聊过的话题。
- 每位角色一天最多成功主动发送一条；刚聊过的 90 分钟内暂不发。连续两次未回复时至少间隔 48 小时。自然模式在用户超过七天没有发言后等待用户回来。
- 默认 23:00–08:00 免打扰，可以在设置调整。错过整点后只在当天合适时段恢复，不堆积往日消息。
- 模型使用角色设定、用户明确保存的私有/插件记忆、近期文字对话和最近主动问候。不把图片、语音附件重新外发给问候模型，也不会读取手机其他应用。
- 提示词要求不编造用户近况、敏感经历、生日或纪念日，不宣称持续观察，不用内疚或占有欲催回复。生成后的相似度检查能减少重复，但不能保证模型永远不重复或不产生错误。

## 后台、重试与费用

Android 使用系统 JobScheduler，约十五分钟是检查周期的最低间隔，并非准点闹钟。实际执行会受网络、系统调度、小米省电设置等影响。强制停止后必须重新打开应用；长时间未打开、上下文计划过期时暂停后台生成。电脑需保持程序运行或最小化，退出后暂停。

每次请求都可能使用模型额度。每位角色每天最多三次尝试，普通失败按 15/30/60 分钟退避，限流至少等待三十分钟；服务端已有的设备、IP、全站和预算保护仍生效。Android 另设整机主动问候每小时最多六次、每天最多二十四次的请求上限。已生成并保存的待投递回复会恢复投递，不再为同一回复重新调用模型；网络中断发生在服务商已经生成但本机尚未收到或保存结果时，无法保证服务商不会计费。

后台计划、尝试记录和待收消息保存在 Android 本机加密存储，使用现有系统密钥；接口密钥仅以受地址约束的本机凭据引用传递。通知默认不显示聊天正文，点击后进入对应会话。后台服务不直接改写前台聊天快照，前台收到消息并保存成功后才确认接收。

## 验收范围

配套测试覆盖托管模型、记忆上下文、免打扰、冷却、重试、取消、重复消息、持久化恢复、原生桥接权限和消息确认。桌面完整流程通过隔离资料与本机模拟模型执行；这些结果不等于真实模型回复质量或小米实机后台行为已验证。Android 新后台实现需要在实际手机上验收通知许可、后台送达和电池管理行为。软件的自定义头像、长按收藏图片表情继续保留。

验证记录随本次交付另附，历史记录保留。新版沿用原包名和签名，支持直接覆盖安装升级；不要先卸载，否则可能丢失设备上的聊天资料。
